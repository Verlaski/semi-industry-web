# 免费行情数据源技术可行性调研报告

- 调研日期：2026-10-15（盘中实测，A股交易时段）
- 测试环境说明：本机 Windows，网络走本地代理（Clash 类 TUN，198.18.x.x fake-IP）。部分国内域名（push2.eastmoney.com 主域、api.money.126.net）在本机被代理重置/拦截，已用同族编号子域（82.push2 等）完成东财实测；CloudBase 云函数部署在腾讯云国内地域，为直连网络，不受本机代理因素影响，该差异已在结论中标注。
- 统一样本：A股 中微公司 688012.SH；港股 ASMPT 00522.HK；美股 Applied Materials AMAT
- 方法：全部源均发起真实请求验证，非文章转述；无法实测的（需注册 Key 的海外源）已用 demo/无 Key 请求验证接口行为并查官方条款。

## 一、逐源实测记录

### 1. AkShare ✅（可用，Python 封装库）
- 本质：对新浪/腾讯/东财/巨潮等网页接口的 Python 封装，不是独立数据源。
- 实测：`stock_zh_a_hist_tx`（腾讯K线）0.9s OK；`stock_zh_a_spot`（新浪全量快照，约5400行）12.2s OK；东财系接口（`stock_zh_a_spot_em`、`stock_bid_ask_em`、`stock_zh_a_hist`）在本机代理下连接重置（网络层原因，非库问题）。
- 需 pip 安装，依赖 pandas 等重依赖。行情字段取决于底层接口。
- 结论：适合本地/研究侧数据管道，不建议嵌进 CloudBase 云函数（包体大、冷启动慢、间接依赖底层网页接口的稳定性）。

### 2. 东方财富 Push2 ✅（推荐）
- 实测端点：`https://82.push2.eastmoney.com/api/qt/ulist.np/get?secids=1.688012,116.00522,105.AMAT&fields=f12,f14,f2,f3,f20,f21,f124` 三市场批量全通；100 只代码一次请求实测 total=90（无效代码跳过）。
- 字段：f2 最新价（需除以缩放，如 29049→290.49）、f3 涨跌幅（%×100）、f20 总市值、f21 流通市值、f84/f85 总/流通股本、f124 时间戳、f57/f58 代码/名称。单票 `stock/get` 的 f292 交易状态字段存在。
- 无注册、无 Key、无 Cookie/Referer；实时（盘中秒级），未见 15 分钟延迟。
- 注意：主域 push2.eastmoney.com 在本机代理下不可达，实测 82/1/72.push2 等编号子域可用（1~99 号段），建议 Adapter 内做子域轮询+失败切换。
- 性质：网页内部接口，无官方文档，字段语义靠社区维护；稳定性风险中（字段变更无预告）。免费无额度承诺，频率限制未公开（实测常规轮询无压力）。

### 3. 腾讯财经 ✅（推荐）
- 实测：`https://qt.gtimg.cn/q=sh688012,hk00522,usAMAT.OQ,sh600519,sz000001` 跨市场混合批量全通；60 只批量实测 OK。
- 字段：`~` 分隔 v_xxx 字符串，含 名称/最新价/昨收/今开/最高/最低/成交量/成交额/五档盘口/时间戳(20261015130151)/涨跌额/涨跌幅/总市值(2749.24亿)/流通市值/PE/总股本(942197038)/52周高低/A股含交易状态位。美股代码格式 `usAMAT.OQ`。
- 无注册/Key/Cookie；GBK 编码需转码；实时，无延迟标记。
- 性质：网页内部接口；无文档；稳定性风险中。实测无任何反爬。

### 4. 新浪财经 ✅（可用，有条件）
- 实测：三市场通（`sh688012` / `hk00522` / `gb_amat`），支持批量。
- **必须带 `Referer: https://finance.sina.com.cn`，否则 403**（实测确认）。
- 字段：价/涨跌/时间戳/五档盘口；A股与港股**无总市值字段**；美股 gb_ 流含总市值（354444425967 实测）。GBK 编码。
- 性质：网页内部接口；稳定性风险中；美股 gb_ 流时间字段较乱（实测出现不一致时间戳）。

### 5. 网易财经 ❌（不可用）
- `api.money.126.net` 连接被重置；`quotes.money.163.com/service/chddata.html` 与 ajax 接口均 502。基本判定已下线或全面封闭。结论：不采用。

### 6. BaoStock ✅（A股日终兜底）
- 实测：匿名 `login()` 成功；`query_history_k_data_plus("sh.688012", ..., frequency="d")` 0.3s 返回，含 open/high/low/close/preclose/volume/amount/turn/tradestatus/pctChg/isST。
- 当日（2026-10-15）日K在收盘后才入库——适合日终校准，不适合盘中刷新。
- 仅 A股（无港美股）；无总市值/总股本字段（需另算）。Python 依赖，协议为私有 socket 登录（非纯 HTTP）。
- 结论：作为 A股日终兜底与数据质量核验源合格。

### 7. 巨潮资讯 CNINFO ⚠️（非行情源，官方核验用）
- 实测：`topSearch/query`（POST，需 UA+Referer）返回中微公司代码/orgId 映射；`hisAnnouncement/query` 返回公告结构。
- 不提供行情快照。用途：证券代码↔orgId 核验、公告/股本变动文件核验、上市公司基本信息权威来源。

### 8. 上交所 SSE ✅（官方核验，沪市场）
- 实测：`https://yunhq.sse.com.cn:32042/v1/sh1/snap/688012`（**必须带 Referer: https://www.sse.com.cn/**）返回 name/high/low/open/last/change/chg_rate/volume/amount/tradephase(T111 连续竞价)/date+time。
- `?select=` 支持字段筛选；总市值类字段实测返回 null（默认快照不含市值/股本）。
- 仅沪市；批量（逗号多代码）实测 404，不支持。官方性质，稳定性高。

### 9. 深交所 SZSE ✅（官方核验，深市场）
- 实测：`https://www.szse.cn/api/market/ssjjhq/getTimeData?marketId=1&code=000001`（需 Referer）返回 now/open/high/low/delta/deltaPercent/marketTime/五档。
- 仅深市；沪市代码实测返回空（code=-1）。官方性质，稳定性高。无市值字段。

### 10. 北交所 BSE ❌（云函数不可直接用）
- 官网 www.bse.cn 可达（200），但行情接口 `nqhqController/nqhq.do` 在网宿 WAF（Server: wswaf）之后：直接请求 403/302 安全校验跳转。无浏览器会话不可用。北交所标的（如 92xxxx/83xxxx/87xxxx）只能用东财/腾讯等源交叉核验。

### 11. 雪球 ❌（反爬明显）
- 无 Cookie：403 `Seek IP Blacklisted`；带首页 Cookie：400 `error_code 400016`（需登录态 xq_a_token）。服务器/云函数 IP 段基本被拉黑。结论：不采用。

### 12. Yahoo Finance ✅（港美可用，有条件）
- 实测：`https://query1.finance.yahoo.com/v8/finance/chart/{symbol}` 三市场全通（688012.SS / 0522.HK / AMAT），含 regularMarketPrice/ChangePercent/regularMarketTime/前收/52周高低/成交量。
- **无总市值**（v7/quote 与 v10/quoteSummary 实测 401，需 crumb+cookie，不适合服务端长期维护）。
- 免费无 Key；频率限制未公开（偶发 429，需带 UA）；美股为延时数据（无交易所实时授权；本次实测 regularMarketTime=美东 10-14 16:00 收盘时点）。
- 性质：非官方公开 API（Yahoo 无公开行情 API 许可），稳定性风险中高。

### 13. Stooq ❌（不可用）
- `q/l/` 接口 404 + 返回 JavaScript 浏览器挑战（反爬墙）。不采用。

### 14. Alpha Vantage ⚠️（不适用本项目）
- 需注册 Key。免费档官方条款：**25 次/天、5 次/分**（AV 官方 IEX 迁移页确认，历史上 500→100→25 逐步收紧）。
- 覆盖以美股为主；**不支持 A股；港股股票不支持**。500 只 × 10 分钟刷新完全不可行。接口行为实测（demo Key 通，无 Key 报 invalid）。

### 15. Financial Modeling Prep ⚠️（不适用本项目）
- 需注册 Key（demo Key 401 实测）。免费档 250 次/天（官网），**仅限个人用途**；覆盖美股为主，A股不支持，港股免费档不支持。再展示授权风险高。

### 16. Twelve Data ⚠️（不适用本项目）
- 需注册 Key（demo 401 实测）。免费档 800 次/天、8 次/分，仅 3 个市场（美股/外汇/加密），**A股/港股免费档不支持**；且免费档为 **internal non-display 许可——禁止对外展示价格**，对本项目（网站公开展示）不合规。

## 三、结论与推荐

### 推荐组合
- **A股主数据源**：东方财富 Push2（ulist 批量、JSON 字段语义清晰、总市值/总股本/时间戳/状态齐全、单次 100+ 只）。
- **A股备用源**：腾讯财经 qt.gtimg.cn（跨市场统一协议、无 Referer 要求、实测最稳），主备可在 Adapter 配置切换；新浪作为第三备选（需维护 Referer）。
- **A股日终兜底/核验**：BaoStock（收盘后校准涨跌幅与交易日状态）+ SSE（沪）/SZSE（深）官方快照低频比对；北交所标的用东财/腾讯交叉核验（BSE 官方接口 WAF 拦截，云函数不可直接用）。
- **港股主/备用**：主 腾讯 hk（含总市值、实时）；备用 Yahoo chart / 新浪 hk。
- **美股主/备用**：主 Yahoo chart（价格/涨跌幅/时间可靠）；备用 腾讯 usAMAT.OQ（补总市值、总股本）。
- **官方核验源**：SSE yunhq（沪）、SZSE getTimeData（深）、CNINFO（代码/orgId 映射、公告、股本变动文件）。BSE 接口暂不可自动核验。
- **明确排除**：网易（下线）、雪球（IP黑名单+登录态）、Stooq（反爬墙）；Alpha Vantage / FMP / Twelve Data 免费档（额度与许可不满足 500 只×10 分钟公开展示，且不支持 A股）。

### 三个候选方案评估
- **方案 A（东财主 + BaoStock 日终兜底 + 官方核验）**：✅ 推荐为基座。字段最全、批量最大、与"A股最高优先"最匹配。唯一工程注意点：push2 主域在个别网络环境不可达，Adapter 需做 1~99 编号子域轮询。
- **方案 B（腾讯主 + 同兜底/核验）**：✅ 可作为等价的备选基座，实现最简单（无字段语义文档、无 Referer），跨市场一套协议。`~` 分隔字段按社区文档索引，解析脆弱性略高。建议 A/B 都做进 Adapter，配置切换。
- **方案 C（A股国内源 + 港美 Yahoo，统一 Provider Adapter）**：⚠️ 部分推荐。港美用 Yahoo 的好处是国际代码规范统一、CloudBase 海外可达性好；但 Yahoo 无总市值（v7/quoteSummary 需 crumb 维护）、美股延时、偶发 429。实务上港美用"腾讯为主、Yahoo 为备"更稳。架构原则（统一 MarketDataProvider 接口、不写死数据源）完全正确，应当执行。

**最终建议：以方案 A 为主体 + 方案 B 作主备热切换 + 港美采用腾讯主/Yahoo 备（吸收方案 C 的统一 Adapter 架构），即"A+B+C 混合"，全部通过统一 MarketDataProvider 实现，未来可无痛替换为 Wind/Choice/聚源等持牌商业源。**

### CloudBase 落地架构
1. **运行时**：Node.js（18+，内置 fetch），纯 HTTP 源零依赖；BaoStock 单独一个 Python 云函数仅用于日终兜底。
2. **定时**：云函数定时触发器 cron，每 10 分钟（5~15 均可）执行批量抓取；500 只 → 东财 5 次请求（每次100）或腾讯分批，单轮 < 20 次出站请求，频率压力可忽略。
3. **存储**：云数据库存 `{code, price, pct, mcap, shares, quote_time, source, freshness}`，写前做字段合理性校验（价格>0、涨跌幅±30% 内、quote_time 在 N 分钟内）。
4. **可靠性**：Adapter 内置 主备熔断（主源连续失败 N 次切换）、字段级 fallback（主源缺市值时从备用源补）、子域轮询、UA/Referer 头管理。
5. **合规提示**：所有免费网页源均无行情再展示授权。对内投研网站、非交易终端、标注"数据仅供参考/存在延迟"的实务风险较低；面向公众或商业化时应升级持牌行情源（Wind/Choice/同花顺iFinD/聚源）。Twelve Data 免费档条款明确禁止展示，切勿使用。

### 待办/未验证项
- 腾讯/东财/新浪均未公布频率限制，建议上线前在 CloudBase 真实环境做一轮压测确认阈值。
- BSE 官方接口如未来需要，需评估浏览器指纹模拟成本，当前不建议。
- Yahoo 美股延时特征在盘中时段（美东 9:30-16:00）未实测对比（本机测试时为美股盘后），建议在盘中复核一次。
