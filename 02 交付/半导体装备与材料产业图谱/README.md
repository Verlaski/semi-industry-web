# 半导体装备与材料产业链图谱 · 维护手册

## 这是什么

一个零依赖的静态网站，展示「半导体装备与材料」行业图谱：产业链总图、装备/材料两张子图谱、竞争格局与国产化、数据来源与版本记录。**所有展示内容来自 `data/` 下的 4 个 JSON 文件，维护只需改 JSON，不需要懂前端。**

## 目录结构

```
半导体装备与材料产业图谱/
├── index.html              # 页面骨架（一般不用动）
├── assets/
│   ├── css/style.css       # 样式（一般不用动）
│   └── js/app.js           # 渲染器（一般不用动）
├── data/
│   ├── meta.json           # 站点信息、景气度研判、关键市场数据、设备Top10、趋势要点、版本记录
│   ├── equipment.json      # 半导体装备：全部赛道 + 龙头 + 国产化 + 来源引用
│   ├── materials.json      # 半导体材料：同上 + 基础原料关系
│   └── sources.json        # 事实来源账本（所有数据的出处）
├── 启动本地预览.bat         # 本机预览（双击后访问 http://localhost:8000）
└── README.md               # 本文件
```

## 如何预览 / 发布

- **本机预览**：双击 `启动本地预览.bat`（需本机装有 Python），浏览器打开 `http://localhost:8000`。
  注意：直接双击 `index.html`（file:// 协议）会因浏览器安全策略无法加载数据，必须走 HTTP。
- **正式发布**：把整个文件夹交给 WorkBuddy 静态托管（或任何 HTTP 静态服务器），无需构建。

## 日常维护：改数据

### 改一个赛道的龙头或国产化阶段

打开 `data/equipment.json`（或 `materials.json`），按赛道 `id` 或 `name` 找到对应条目，修改字段：

| 字段 | 含义 | 填写要求 |
| --- | --- | --- |
| `name` / `group` / `chain_position` | 赛道名 / 分组 / 产业链位置 | 改名时同步检查 README 文末赛道清单 |
| `subs` | 二级细分 | 仅当一级赛道内部竞争格局明显不同时使用 |
| `market_size` | 市场规模 | 必带 `year`、`scope`、`source_id` |
| `global_leaders` | 全球龙头 | 2–5 家；`share` 只能写市场份额，没有就写 `N/A（按收入排名）` 等，不得混用口径 |
| `china_leaders` | 国内龙头 | 1–4 家；没有就把数组留空，并在 `note` 写「国内暂无头部厂商」 |
| `localization` | 国产化判断 | `stage` 限五档词表（见下）；`scope`（适用产品范围）必填；`evidence` 一句依据 |
| `note` | 备注 | 数据冲突、口径差异记在这里 |

国产化阶段词表（固定五档，渲染颜色自动匹配，不要自造词）：
`依赖进口` / `验证导入` / `份额提升` / `批量替代` / `国际领先`

### 新增一条来源

所有关键数字必须通过 `source_id` 挂到 `data/sources.json` 的来源条目。新增来源格式：

```json
{
  "source_id": "SRC-MF-99",
  "org": "发布机构",
  "title": "资料名称",
  "publish_date": "2026-01",
  "data_year": "2025",
  "metric": "指标名称",
  "caliber": "统计口径",
  "region": "全球",
  "url": "https://……",
  "access_date": "2026-10-15",
  "type": "行业机构",
  "level": "A",
  "remark": "备注"
}
```

- `source_id` 全库唯一，建议沿用前缀习惯：`SRC-EU` 装备上游、`SRC-EF` 前道、`SRC-EB` 后道、`SRC-MF` 制造材料、`SRC-MP` 封装材料、`SRC-OV` 行业总览。
- 证据等级：**A**=SEMI/WSTS/TechInsights/TECHCET 等行业机构正式数据或上市公司年报/招股书；**B**=权威研究机构正式报告且口径可确认；**C**=公司官网/公开采访/行业媒体；**D**=二手转载（不得单独支撑核心结论）。

### 改景气度、驱动力、Top10、趋势

在 `data/meta.json`：`prosperity`（装备/材料景气度）、`facts`（关键市场数据卡片）、`drivers`、`equipment_top`、`trend_notes`。

### 发新版

1. 改完数据后更新 `meta.json` 里的 `updated`（数据更新日期）和 `version_log`（在数组最前面加一条版本记录，说明本次改了什么）。
2. 自查清单（提交前逐项过）：
   - [ ] 每个赛道全球龙头 ≥2 且 ≤5 家，国内外分开标注
   - [ ] 每条关键数据都有 `source_id`，且该编号在 `sources.json` 中存在
   - [ ] 市占率带年份与口径；无份额数据写了「N/A（按…排名）」
   - [ ] 国产化阶段用的是五档词表，且附适用产品范围
   - [ ] 石英/陶瓷/硅等设备耗材没有同时出现在装备与材料两侧
   - [ ] 全文检索确认不含任何客户信息（客户名称、客户经理等内部信息）

## 赛道目录（v1.0 锁定）

装备链：上游·核心零部件与子系统（真空系统/射频电源/气体流量控制/温控/精密运动/静电吸盘/光源激光/光学/机械手传输/石英件/陶瓷件/金属及硅基件）→ 中游·前道（光刻/涂胶显影/刻蚀/薄膜沉积/清洗/热处理/离子注入/CMP/量检测）+ 后道（封装/测试）→ 下游·晶圆制造与封测。

材料链：基础原料（示意）→ 晶圆制造材料（硅片/光掩膜/光刻胶及配套/电子特气/湿电子化学品/CMP材料/靶材/前驱体）+ 封装材料（封装基板/引线框架/键合丝/塑封料/芯片粘结/底填料/陶瓷封装）→ 晶圆制造与封测。

新增赛道时保持同一粒度纪律：**拆到一个赛道能识别 2–5 家公认头部企业为止**；赛道内部格局差异大时拆二级细分，不要新增并列一级赛道凑数。
