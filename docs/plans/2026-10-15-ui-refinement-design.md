# V1.1 前端与抽卡体验调整

主图动效追加：仅处理 `.map-section` 内的原生 details，保留鼠标/键盘和原生无脚本行为。summary 使用浅蓝青 hover/focus-visible 底色；通过 Web Animations API 在当前高度与目标高度间过渡 240ms，关闭完成前保持内容可渲染。批量操作先设置全部嵌套状态，再只动画外层，避免父子重复动画；快速反向点击取消旧动画并从当前高度接续。完成、切页、减少动态效果设置变更均清理动画和临时裁切样式。

同日追加：按最新反馈，推荐入口改为仅骰子图标的荧光色点缀；统一实际路由的选中背景/下划线并补 aria-current。股票代码从 Mono 改为与正文相同的 Sans，来源 ID 继续 Mono。主图批量展开/收起按钮使用浅蓝青底，hover/focus-visible 同时切换为蓝青底白字，避免局部默认背景覆盖通用 hover 样式。

用途：本次实现与验收清单。读者：负责人、KimiCode。日期：2026-10-15。

根据追加需求，采用蓝青#087F98、荧光黄绿#D6F94A、浅灰#F3F8F8，统一 Noto Sans SC 开源字体，代码/Source ID使用一个通用Mono字体栈。以600/700字重和留白区分标题。缩短顶部，增加列表留白与局部悬浮反馈。保留三栏产业链，以原生 details 按全球、国内和二级分类折叠；标题与三列表头组成受主图边界约束的固定条。移动端改为按列固定栏目标题。总览表使用有高度上限的滚动区及固定表头。

相比整页浮动卡片，此方案保持三段产业关系清晰，减少滚动和视觉干扰；相比全部收起，只保留赛道名称与阶段入口，展开后仍能直接点公司，详细证据继续在侧栏查看。

正文只留影响使用的说明，其余集中到页脚折叠区。来源表精简五列，不使用跑马灯，点击资料名或角标打开右侧全文卡。抽卡单抽与十连使用不同原创 SVG 图标，准备阶段轮换三组文案并显示进度；金/深紫/蓝灰卡面对应核心龙头、重点跟踪、产业观察及5/4/3星。分类以既有关系及可维护产品跟踪范围为依据，规则详见数据模型；均匀随机概率不变，角落常驻非投资评级说明。短时彩条在揭晓后播放，重抽/切页清理，减少动态效果时直接揭晓。

验证：现有单元测试、角色颜色分类测试；桌面及窄屏检查，折叠与公司侧栏、固定表头边界、来源长文本、单抽/十连/空池、清单复制、减少动态效果；发布后检查资源状态及字体响应头。研究 JSON、后台和 PDF 保持原状。

## 后续追加：荧光黄主色、结构图与最终交接

主辅色按新意见对调：#DFFF00作主色，#087F98作辅色，Hero深字。总图添加原生SVG双链汇流图，移动端在图内横向滚动；38个赛道以按钮全行左右对齐名称与阶段，只开Drawer不跳route。移除深链接累积的表格行高亮。

用户明确要求骰子emoji，推荐导航单独突出；等待文案三阶段各10句独立随机。公司表复用现有三证券API显示最新价、涨跌额/幅和原币种市值，红涨绿跌，最近缓存更新时间置表上；缺少正式listing时只允许三条显式试运行显示桥，不推断其他身份。

交接扩成用户要求的十部分，区分当前支持与目标契约，特别明确独立关系文件、source_ids复数和PDF主表名称解析仍需小范围适配。发布提交后导出核对远端SHA的最终交接快照。
