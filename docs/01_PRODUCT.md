# 产品说明

用途：说明当前网站能做什么。读者：项目负责人及使用者。更新时间：2026-10-15。对应版本：V1.1。

网站服务产业研究、同行比较、IPO与资本运作标的跟踪。产业分类、公司名单、份额、国产化与来源均取自现有研究数据；本轮不重新核实主体和产业结论。

主要使用者是投行项目组、行业研究与并购业务人员。可以沿“装备→刻蚀→公司→来源”了解产业，也可以从公司库反查它涉及的赛道、产品与竞争格局。

```text
产业链总图
  ├─ 装备图谱 / 材料图谱 → 赛道详情 → 公司详情
  ├─ 龙头公司库 → 搜索筛选 / 主上市地小时行情
  ├─ 竞争格局 → 国产化对照
  ├─ AI推荐跟踪龙头 → 随机研究清单
  └─ 数据来源 → 原始资料与证据等级
```

赛道指一类产品或工艺，二级细分是其中更具体的子产品。全球龙头与中国龙头是原研究名单中的角色，不代表本轮重新确认排名。国产化阶段描述赛道的进展；它不是公司的固定属性。份额必须连同报告期、范围和来源阅读，不能把不同口径直接相加。

主导航依次为产业链总图、装备、材料、公司库、竞争格局、AI推荐跟踪龙头、来源。公司、赛道和来源的侧栏覆盖在原图之上；关闭后回到原位置，支持Esc、键盘焦点约束及移动端。

主图中的全球/国内龙头、二级分类及嵌套分类在悬停或键盘聚焦时使用浅蓝青背景。展开与收起采用 240ms 高度动效，支持连续切换和批量操作；动画结束恢复自然高度，切页主动清理，系统开启减少动态效果时直接切换。

界面采用荧光黄#DFFF00主色、蓝青#087F98辅色，Hero深色字、正文保留蓝青标题/链接；保留轻量卡片结构。全站一套本地Noto Sans SC，标题以字重/字号区分，证券代码也使用 Sans，Source ID 使用 Mono。顶部只显示数据更新日期。总图增加双链汇流结构图，赛道名称与阶段左右对齐，点装备或材料赛道只开侧栏、保留总图；不再给点过的总览表行留下持久底色。长篇口径在页脚折叠区；长表有独立滚动区域和固定表头。

导航仅以荧光黄骰子图标突出“🎲 AI推荐跟踪龙头”，整栏底色和下划线仅用于实际选中的页面。抽卡准备动画持续约2.4秒，三阶段各随机取10句之一，最多1000种等待组合；期间禁止重复抽取，改变筛选或切页会取消准备与礼炮。减少动态效果设置下直接揭晓。卡面等级仅表示产品跟踪标签，不构成投资评级；具体规则见[数据模型](02_DATA_MODEL.md#卡面跟踪标签)。

当前没有交易级实时行情、PE/PB和完整财务数据库，也没有公告/新闻自动更新、用户账户与收藏。这些功能不属于本轮交付范围。

公司库当前使用 245 家正式实体（上市 171 / 非上市 74），按 company_id 去重；其中 6 家 IPO 在审仍属非上市。抽卡基于正式公司与赛道关系，地域/上市状态/逐赛道支持下拉复选。Compatibility Adapter 仅保留作正式主库 404 时的历史回退，不是当前数据来源。

抽卡理由来自已有赛道角色、名称及国产化阶段，再加已确认的上市状态。没有评分模型，也不调用在线大模型。抽卡用于轻量产业发现，不构成投资建议。

“复制清单”优先写入剪贴板；浏览器限制复制时展开可选中的文本框，并提供独立下载按钮，避免清单被浏览器丢弃。

行情注册范围为 96 只 SH/SZ/BJ/HK/US 证券，按公司主上市地并入表格：最新价、涨跌额、涨跌幅、总市值，红涨绿跌。表格上方显示最近成功获取缓存的时间，单元格保留证券行情时间/状态。注册表保留 listing_id，数据库缓存仍以 symbol 为键。兼容模式不再提供证券推断关联。腾讯为当前云端优先源；东方财富云端连接仍待恢复。休市时段显示收盘行情，尚未接完整节假日日历。最新发布验收见 [迭代验收](RELEASE_2026-10-15.md)。

在线访问可能先出现腾讯云测试域名访问提示。该提示由平台提供，页面确认后进入站点；不影响后端API的JSON/PDF响应。实际验收结果见操作手册的验收记录链接。
