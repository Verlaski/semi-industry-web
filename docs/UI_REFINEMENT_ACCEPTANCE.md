## 验证限制

减少动态效果分支和CSS已检查：跳过准备、禁用彩条与动效；未改变用户系统的动态效果设置来做运行时切换。

“复制清单”线上返回“跟踪清单已复制”，但本轮IAB工具读取剪贴板为空，因此未确认操作系统剪贴板内的10行文本。该复制实现未在本轮改动，原有失败时展开文本框及下载清单兜底仍保留；交接时可用实际浏览器手工粘贴复核。

静态托管HTTP响应仍带平台既有Content-Disposition: attachment；本轮真实浏览器能直接渲染页面、加载CSS/JS和woff2，未修改共享托管配置。没有重跑后台PDF生成，本轮未涉及报告逻辑。
