# 验收说明：公司主数据库与行情扩容（V1.1 数据正式化）

写给项目负责人 · 2026-10-15 · 对应 commit `52123e0`

先花一分钟说清背景：这个网站此前的"龙头公司"只是写在赛道数据里的文字（比如"中微公司 AMEC"这串字），同一家公司在刻蚀、薄膜两个赛道各写一遍，没有统一的"公司档案"，也没法接股价。本轮把公司升级为**独立档案**：每家公司一份档案（`companies.json`），赛道里只写"谁在这个赛道是什么地位"并通过编号 `company_id` 关联过去——这就是本轮全部工作的核心。

## 一、上市状态怎么判断、数据来源是什么

### 判断流程（每个公司走同一套流水线）

```
赛道原始名单（249 行候选，含组合名/简称/旧名）
   ↓ 分批：主体异常批（斜杠组合/疑似重复/母子关系）先裁决"这是几家公司、是哪一家"
   ↓ 上市核验：分国家批次查"上没上市、在哪上市、代码是什么"
   ↓ 交叉验证：160 只证券的"代码↔公司名"用行情接口反查复核（160/160 一致）
   ↓ 合并入库，0 冲突、0 未匹配
```

### 数据来源分级（每条上市信息都有出处，在网站"数据来源与版本"页可查）

- **A 级（最硬）**：交易所官网（上交所/深交所/北交所/JPX/纳斯达克）、公司官网投资者关系页、招股书/年报——海外公司批（美/欧/日/韩台）基本做到 A 级全覆盖
- **B 级**：东方财富、腾讯行情、雅虎财经等数据站——中国批 94 家主要走这条路：脚本自动查询东财证券名录（返回官方板块归属如"科创板/京A"）+ 腾讯行情接口反查公司名，两个独立源对上才算确认
- **C 级**：行业媒体报道，仅作佐证，不单独定结论

### 三条纪律（您验收时可以盯着查）

1. **查不到 ≠ 非上市**：只有找到正面证据（官网无上市记录、IPO 辅导备案、权威报道）才写"非上市"；真查不到的留空，页面上显示"待补充"而不是误判
2. **子公司不继承母公司代码**：比如凯世通（万业企业旗下）、UP Chemical（雅克科技子公司）本体未上市，就标"非上市"，母公司代码写在备注里，绝不张冠李戴
3. **斜杠组合全部拆开**：原始数据里"Nikon/Canon"这种写法，拆成尼康、佳能两条独立档案；"EVG/SUSS"拆成奥地利 EV 集团（非上市）和德国 SUSS（法兰克福上市）两家

### 几处值得一提的纠错（核验的真实价值）

- **MKS Instruments** 已于 2025-05 更名为 MKS Inc.（万机仪器）
- **新川（Shinkawa）** 已并入雅马哈机器人，不是独立上市公司
- **EVG** 的记录里被研究代理误挂了竞争对手 SUSS 的股票代码，人工复核发现后剔除
- **Advanced Thermal Sciences** 与奥地利 AT&S（奥特斯）编号碰撞，拆清
- **JSR** 已私有化退市、**Kokusai Electric** 2023 年东证 IPO——都已按 2026 年现状修正

## 二、companies.json 每个字段是什么意思

文件位置：`02 交付/半导体装备与材料产业图谱/data/companies.json`，结构为 `{"companies": [245 条档案]}`。每条档案：

| 字段 | 意思 | 例子（中微公司） |
|---|---|---|
| `company_id` | 公司唯一编号，全库不重复；赛道里用它引用 | `AMEC` |
| `name_cn` | 法定中文全称 | 中微半导体设备（上海）股份有限公司 |
| `name_en` | 英文法定名 | Advanced Micro-Fabrication Equipment Inc. China |
| `short_name` | 页面上显示的简称（防全称过长） | 中微公司 |
| `aliases` | 确认过的旧名/别名（更名史、收购前名） | ["中微半导体"] |
| `country_region` | 注册地 | 中国 |
| `listing_status` | 上市状态，只有三个值：`上市` / `非上市` / 空（未知） | 上市 |
| `listings[]` | 上市记录数组，多地上市就有多条 | 见下 |
| ↳ `listing_id` | 这条上市身份的编号（公司_交易所），行情关联键 | `AMEC_SSE` |
| ↳ `market` | 市场词表：A股/港股/美股/日股/欧股/台股/韩股/其他海外 | A股 |
| ↳ `exchange` | 交易所 | SSE |
| ↳ `ticker` | 标准股票代码（带后缀） | 688012.SH |
| ↳ `primary` | 是否主上市地（多地上市时标 true 的那条） | true |
| ↳ `provider_symbols` | 行情供应商的代码格式（A股/港股/美股才有） | tencent: sh688012 |
| `listing_source_id` | 上市信息的核验来源编号（对应 sources.json） | SRC-LS-xxx |
| `source_keys` | 研究溯源：这家公司来自候选池哪几行 | ["AMEC"] |
| `entity_decision` | 主体裁决记录（拆分/合并/母子关系的结论和依据） | — |
| `confidence` | 核验置信度 high/medium/low | high |
| `unresolved` | 遗留未决事项（如"法定英文名未确认"） | — |

**字段归属原则**（防止数据越改越乱的红线）：公司名称/地区/上市信息 → 属于公司档案；市场规模/国产化阶段 → 属于赛道；**市占率/产品线/龙头地位 → 属于"公司×赛道"的关系**，留在赛道数据里，绝不写进公司档案。同一家公司在刻蚀赛道和薄膜赛道的份额可以不同，所以这些字段天然不属于公司本身。

## 四、目前仍不完整的东西（诚实清单）

| 缺口 | 影响 | 建议 |
|---|---|---|
| **线上尚未部署** | 以上一切只在本地/GitHub，线上网站还是旧版 | 由 codex 按交接文档部署 semiApi + generateReport（必须同一构建，否则 PDF 报错） |
| **日股/欧股/韩股/台股无行情** | 这些市场的公司行"最新价"列显示"—"（上市信息是全的，只是没接行情） | 后续在行情 Provider 层验证对应市场代码前缀后扩注册表 |
| **87 家有未决项** | 主要是：部分公司法定英文名未确认、几家 IPO 审核中的公司状态会变化（华卓精科/珠海越亚/猎奇智能等） | companies.json 每条的 `unresolved` 字段就是待办清单，建议下轮滚动复核 |
| **部分来源为 B 级** | 中国批主要依据东财/腾讯接口（B 级），未逐家打开年报/招股书（A 级） | 重要公司可定向补 A 级证据升级 |
| **PDF 未经云端重验** | 本地逻辑保证报告正常（leader 保留了显示名），但云端四类 PDF 未实际重生成 | 交接文档已提示 codex 跑 `tools.verify_online` |
| **光通信行业图谱未启动** | 部门认领的另一个行业（光通信与互联）本轮未涉及 | 10-18 截止前如需交付，建议照本项目流水线复用 |
| **行情频率** | 每小时同步一次，非实时 | 产品设计如此（产业跟踪非交易终端），如需更高频改 cron 即可 |
