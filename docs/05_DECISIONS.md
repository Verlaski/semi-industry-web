# 关键决策

用途：保留重要方案的原因。读者：负责人及后续开发Agent。更新时间：2026-10-15。对应版本：V1.1。

| 编号 | 决定 | 原因与影响 |
| --- | --- | --- |
| DEC-001 | 装备链与材料链并行、保留原taxonomy | 两条投入链汇入制造/封装，本轮产品开发不重做研究框架 |
| DEC-002 | 使用CompanyRepository隔离正式公司库 | 公司主数据由另一开发线负责；兼容模型不分配最终company_id、不发布研究草稿 |
| DEC-003 | 公司、赛道与行情分别维护 | 公司固有属性与份额/产品/国产化关系属性不同，动态价格也不应写入静态研究JSON |
| DEC-004 | 赛道/公司/来源详情使用侧栏，主卡名单局部折叠 | 用户本次要求缩短产业链；全球/国内及二级分类使用原生details按需展开，长篇证据继续放侧栏；标题与栏目在主图边界内固定 |
| DEC-005 | 保持HTML/CSS/原生JS | 延续现有可维护架构，不引入React/Vue或外部前端CDN |
| DEC-006 | 行情通过后端缓存，每小时更新 | 网站用于产业跟踪；减少供应商请求、跨域与前端依赖，不建设交易级实时终端 |
| DEC-007 | 可配置双Provider与最后有效值 | 已实测云端东方财富连接失败、腾讯可用；腾讯优先运行，保留切换能力和供应商限制说明 |
| DEC-008 | PDF采用统一ReportLab Engine + Builder | 数据、结构、样式与组件分离；换数据即可重建，避免每页脚本与网页截图打印 |
| DEC-009 | 云端使用Noto Sans SC及独立FontResolver | Linux不能依赖Windows字体；开放字体可部署，OFL许可证随仓库保存 |
| DEC-010 | 报告使用私有数据库缓存和短时签名下载 | 实际Storage桶为公共读；既不改变既有桶，也不创建新付费桶。后续可以接入私有Storage适配器 |
| DEC-011 | 抽卡采用条件均匀随机、无放回 | 产品用于娱乐性产业发现；理由仅拼接已有字段，不做黑箱评分或在线LLM生成 |
| DEC-012 | 复用现有静态托管子目录与独立SCF网关路由 | 用户交接手册已实测这条路径；保持其他站点和服务可用，不盲目迁移部署产品 |
| DEC-013 | 产品与研究版本分开 | 前端V1.1不代表研究数据被更新；内容摘要进入缓存版本，样式/字体摘要另作renderer_version |
| DEC-014 | 蓝青/荧光黄绿，一套Sans加编号Mono | 按用户追加意见替换藏青/金色，保留现有页面结构；Noto Sans SC本地OFL字体避免外部字体请求与授权不明素材 |
| DEC-015 | 金/深紫/蓝灰卡面是跟踪标签 | 用户要求游戏式稀有度；基于既有角色、细分和tag做透明规则，保持无权重随机，角落明确非投资评级。紫色仅用于用户明确指定的卡面类别 |
| DEC-016 | 来源精简列表，点击右侧全文 | 用户追加要求取消自动跑马灯；长文本单行省略，鼠标与键盘均能打开完整资料，不再使用自动滚动 |
| DEC-017 | 荧光黄#DFFF00为主色，蓝青为辅色与正文链接色 | 按用户新意见对调主辅色，Hero深字保持对比度，保留现有轻量结构；骰子emoji为用户明确指定的推荐导航标识 |
| DEC-018 | 总图直接开Drawer，不切产业标签，也不保留行高亮 | 原深链接曾积累hl样式，误显为特殊研究分类；总图按钮只打开详情，外部旧深链接继续可用 |
| DEC-019 | 公司表内行情采用显式试运行桥 | 复用已部署三证券API与Provider，红涨绿跌；不从未核验代码猜报价，不向兼容主表写上市身份，待listing_id迁移移除临时桥 |
| DEC-020 | 最终交接快照自动核对GitHub SHA | 避免在文档自身写入自身提交SHA的循环；维护版与代码同次提交，推送后导出含精确HEAD和核对时间的交付快照 |
| DEC-021 | company_id 用英文缩写/拼音助记符而非数字代码 | 可读、稳定、与赛道编号风格一致；数字代码会变（更名/换板），助记符不变；规则写入 DATA_MODEL |
| DEC-022 | 赛道 leader 保留已核验显示 name 并加 company_id 双写 | PDF Builder 读 name 无需改动即可出报告；前端按 company_id 连接正式主表；后续如要 ID-only 再加薄层解析 |
| DEC-023 | 行情注册表由公司主表生成、symbol 不变 | symbols.generated.js 从 listings 生成并携带 listing_id；symbol 作缓存键不变，旧行情缓存可回退；首批只覆盖腾讯已实测的 SH/SZ/BJ/HK/US 五类前缀 |
| DEC-024 | 中国批上市核验用东财名录+腾讯行情接口脚本化 | 模型额度中断后的替代路径；接口核验（名称↔代码↔板块）为 B 级证据，置信度分级保留人工复核入口 |

PDF视觉规范来自[Verlaski/cn-pdf-report-style](https://github.com/Verlaski/cn-pdf-report-style)，保留A4、藏蓝#17375E、中文研究排版、斑马纹、来源和页码。实现中修正默认Frame内边距导致表宽超出正文的问题，并将科学计数上标转换为真正的上标排版，来源注与表格尾行共同分页，避免注释单独占页。

数据安全规则采用最小作用范围：三个新集合仅服务端访问；只为semiApi增加公共调用，syncQuotes/generateReport仅供管理端、定时器和服务端调用。环境共享的其他函数规则和通配条目保持原值。
| DEC-025 | 上市状态用独立字段而非扩充 listing_status 词表 | IPO在审是过程状态不是上市结论；保留 listing_status=非上市，用 ipo_status 承载在审信息，前端徽章与筛选不破坏现有值域；注册同意待挂牌属同字段管理 |
